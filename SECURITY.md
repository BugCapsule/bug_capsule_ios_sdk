# Security policy

## Supported versions

BugCapsule SDKs are in beta. Security fixes go into the latest published beta release only, so please upgrade before reporting.

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Email **contact@bugcapsule.com** with:

- the package and version affected,
- what an attacker could do, and
- steps or a small project that reproduces it.

We will confirm receipt, keep you informed while we investigate, and credit you in the release notes if you would like.
